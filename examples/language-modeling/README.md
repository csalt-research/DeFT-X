## Language Modeling using MLM
To train DeFT-X lang vectors for AmericasNLI languages:
```
./train_mlm_nli.sh <language_code>
```

Example:
```
./train_mlm_nli.sh bzd
```

To train DeFT-X lang vectors for NusaX languages:
```
./train_mlm_sa.sh <language_code>
```

Example:
```
./train_mlm_sa.sh mad
```
